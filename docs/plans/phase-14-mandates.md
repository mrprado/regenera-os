# Phase 14: Mandates, matching, qualification, approvals, pursuits

Spec: the user's master prompt of 2026-09-30 (§1–100) plus the EMC, Sentinel and market-benchmark notes. Principle: **Mandate → Universe → Signals → Match → Qualify → Approve → Engage → Pursuit → … → Learn**, one engine for every side of the market. A commercial mandate is not the `mandates` table (workspaces); every row carries `mandate_id` = the owning workspace.

## Guarantees
Readings are categorical with a basis; no hidden score. The machine stops at pre-qualified; qualification and every later stage need recorded criteria (person + basis). The client approves by name; approval fixes attribution (pre-existing accounts → client originated) and records an approval. A pursuit opens only after approval; a Go is refused over a blocker; stage changes need a reason. Inferences (EPC value, window, IA-progress signals) are labelled. Success fees are potential only and flagged for counsel. Public lines need owner approval and cannot name the client.

## Performance and go-live (2026-10-01)
- Long work is background jobs, never one request: `mandates.queue.sync` (one per public queue, batched upserts; unchanged
  rows get one bulk `last_seen_at` touch per 90 keys) and `mandates.universe` (400-source slices, D1 `batch` writes,
  each slice re-enqueues the next). The mandate page drives its own queued jobs while open (`continueMandateWorkAction`
  → `runJobsOfTypes`) and shows progress; the 5-minute cron finishes anything left. Progress lives in `system_state`
  (`mandate_work:<id>`). Full EMC rebuild (1,219 candidates): ~22 s in 4 chained jobs, each slice ~1.5–2 s.
- Reads: Today runs every independent read in one parallel round (only "needs attention" waits for the alert sets);
  `mandateCommand`, the email overview and Reports (`computeMetrics` starts its independent reads together) likewise.
- Payload: Universe is paginated at 100 rows; the client approval queue shows the 25 highest-priority items.
- Measured on the local production build (`npm start`, port 8787), 106 pages (every navigation link plus mandate,
  candidate and email detail tabs): all 200, no error boundaries, median 252 ms, 95 under 500 ms; slowest Reports
  ~1.6 s, Today ~1.0–1.3 s. Live D1 adds a network round trip per read wave, so expect somewhat higher absolute numbers.
- `REFERENCE_VERSION` bumped so the MISO / SPP integrations are seeded on the first live tick.
- Security: the mail import endpoint needs `MAIL_IMPORT_TOKEN` in production; the tick-token fallback is localhost-only.
- Phone: header never overflows (≤560 px hides the workspace switcher); verified at 375 px with no horizontal scroll.
