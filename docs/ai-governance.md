# AI governance

- Claude runs server-side only, with versioned prompts in D1 and every call logged (tokens, cost) against a monthly
  budget. No Anthropic key is set yet, so AI features are idle.
- **Proposals, not actions:** Ask the OS and the MCP server can read scoped data and propose changes; nothing is
  written until a person confirms.
- **Never:** certify engineering, give final legal or compliance sign-off, perform regulated solicitation, or turn an
  inference into a verified fact. Regulatory conclusions are recorded only as reviews by named people with evidence.
- **Private investor data and KYC** are excluded from AI tools (tested).
- Every generated message passes the house-style validator and the approval queue; investment communications also
  pass the compliance gate at send time.
