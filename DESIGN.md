# Regenera OS — Operating clarity

This request replaces the flat, crowded composition while retaining the Regenera identity and the entire workflow ecosystem. It supersedes the older shape/type treatment for the redesigned application surfaces; backend and content constraints remain authoritative.

## Use scene and strategy
A founder and analyst work through projects, evidence and decisions on a laptop in ordinary daylight. Use a light working canvas, graphite navigation, legible data, and concentrated gold/rust accents. The shell is a stable control surface; content is the work.

## Composition
Persistent navigation groups distinguish primary work from specialist workspaces. Dropdowns are bounded disclosure panels with task-ordered sections, a clear group destination, and honest permission filtering. Command leads with context and a next step; the large brand statement, regenerative lens and detailed operating desk stay available without dominating daily tasks.

Project 360 retains every tab but groups them in the order a project develops. Its operating views use a compact task chooser and grouped navigation rather than ten equally prominent tabs. Overview pages present attention, relevant records, and tools in the same hierarchy.

## System
Geist UI type, stronger title/body scale, 16px body and 14px regular control/label text. White surfaces on a cool neutral workspace; graphite chrome, restrained mineral gold, and semantic rust/water/energy/risk colors. Soft 8–12px structural corners, shallow surface depth, clear separators, 40–44px controls and generous separation between work areas. No gradients, decorative landscapes, made-up metrics, or excessive icon tiles.

## Behavior

Command placement update (October 6): keep the Scan / Review outreach / Add opportunity action row first, followed by global Atlas activity, then the workspace/regenerative-purpose disclosure. The launcher label is “Scan”.
Link labels open records; separate disclosure controls open grouped tools. Escape closes a disclosure and restores focus. Navigation is semantic links, not an ARIA application menu. Menu search exposes every authorized tool and a meaningful empty state. Keep current route and selected query state visible. Mobile uses an explicit navigation disclosure; specialist options remain available.

## Content preservation
Preserve routes, material copy, workflow states and all distinct destinations. Consolidate only exact duplicate menu destinations within one group, retaining their alternate search terms. Cross-module shortcuts are intentionally preserved. Status options follow their domain lifecycle; entity pickers use grouped alphabetical order. Do not reorder money, units, or legal eligibility options into a misleading priority.
